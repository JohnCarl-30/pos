# Reports Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Summary, Products, Staff and Cash-ups reports for one store over a chosen range, exact to the cent, each with CSV export.

**Architecture:**
- **Database:** read-only `security invoker` SQL functions return the aggregates. RLS and a manager/owner guard limit them to the caller's stores. A shared `private.session_cash` helper is used by both `close_register` and the cash-ups report.
- **TypeScript:** resolves date ranges in the store's timezone, applies the staff flag rules, shapes rows for the screens and CSV, and renders tabs in the `sales-crm` design language.

**Tech Stack:** Next.js 16.4, React 19, Tailwind 4, Supabase Postgres (RLS, pgTAP), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-14-reports-design.md`

## Global Constraints

- **Money:** integer minor units; CSV amounts use `formatAmount(minor, currency)` (major-unit decimals).
- **Range:** `[from, to)`, where `from` is the store's local midnight of the first day and `to` the local midnight after the last day. At most 366 days.
- **Definitions (spec §A):**
  - sales: `created_at` in range and `status <> 'voided'`;
  - refunds: `refunds.created_at` in range;
  - voids: `voided_at` in range;
  - net sales = `sales_total − refunds_total`.
- **Report functions:** `stable`, `security invoker`, `set search_path = ''`, `#variable_conflict use_column`. They call `private.report_guard` first. Execute is revoked from `public, anon` and granted to `authenticated`.
- **Errors:** 42501 'not allowed' (not a manager or owner of the store, or inactive); 22023 'pick a range of up to 366 days'; 22023 'bucket must be hour or day'.
- **Staff flags:**
  - `voids`: `void_count ≥ 2` and `void_count/(sales_count+void_count) > 0.03`;
  - `refunds`: `refund_count ≥ 2` and `refunds_total/sales_total > 0.05`;
  - `cash-void`: `cash_void_count ≥ 1`.
- **Conventions:**
  - no comments;
  - Tailwind only;
  - explicit `Button` variants;
  - `em` max widths;
  - controls on counter screens at least 44px (reports are back office);
  - React 19 patterns: no setState in effects, and controlled inputs.
- **Design:** `DetailSection`, `Stat`, `Card` from `components/_common`; amounts `tabular-nums`, right-aligned in tables.

## Rulings made while planning

- **Export route location:** the CSV route lives at `app/(app)/reports/export/route.ts`, next to the existing `app/(app)/products/export/route.ts`, not `app/reports/export`. Same URL (`/reports/export`), same pattern as products. Cost if wrong: moving one file.
- **`private.div_half_even` becomes executable by `authenticated`.** The invoker `report_summary` needs it for the average sale. It is a pure maths function. Cost if wrong: one revoke, with the average computed in TS instead.
- **Staff row links:** "See voids" and "See sales" (not "See refunds"). The Orders list filters by the cashier who rang up a sale, so a "refunds" link would show the wrong thing. Cost if wrong: a refunds filter on Orders later.
- **Trend bar heights use an inline `style` height:** they are data-driven, and Tailwind can't express runtime values. Everything else stays Tailwind. Cost if wrong: none.
- **Hourly buckets on daylight-saving days:** they are generated over local wall-clock hours, so there are always 24 labels. On a "spring forward" day one hour is empty; on "fall back" the repeated hour's sales share a label. Cost if wrong: a chart off by one bar on two days a year.

## Review Focus

1. **A sale at 00:30 local that is UTC "yesterday":** it must land on the local day and in the local hour. *Pinned in Task 1's pgTAP (order at 01:30 +08).*
2. **A refund on a later day of a sale from an earlier day:** it counts on the refund day in summary, trend, products and staff, and the earlier day is untouched. *Pinned in Task 1.*
3. **"Today" when the server's UTC date differs from the store's local date:** it must be the store's date. *Pinned in Task 2 (Manila at 17:30Z).*
4. **Cash-ups agreeing with close till:** they must use one shared formula. *Pinned in Task 1 (`session_cash` compared with `close_register`).*
5. **Manager whose default store is not the one asked for:** reports follow the sidebar store, and a manager without access to a store gets 42501, not empty numbers. *Pinned in Task 1 (other store's manager) and Task 5 (e2e switches store).*

create index orders_store_id_voided_at_idx on public.orders (store_id, voided_at) where voided_at is not null;

grant execute on function private.div_half_even(numeric, numeric) to authenticated;

create function private.session_cash(p_session_id uuid)
returns table (opening_cash bigint, cash_sales bigint, cash_refunds bigint, expected_cash bigint)
language sql
stable
security invoker
set search_path = ''
as $$
  select rs.opening_cash, s.cash, f.cash, rs.opening_cash + s.cash - f.cash
  from public.register_sessions rs
  cross join lateral (
    select coalesce(sum(p.amount), 0)::bigint as cash
    from public.payments p
    join public.orders o on o.id = p.order_id
    where o.session_id = rs.id and o.status <> 'voided' and p.method = 'cash'
  ) s
  cross join lateral (
    select coalesce(sum(rp.amount), 0)::bigint as cash
    from public.refund_payments rp
    join public.refunds r on r.id = rp.refund_id
    where r.session_id = rs.id and rp.method = 'cash'
  ) f
  where rs.id = p_session_id
$$;
revoke execute on function private.session_cash(uuid) from public, anon;
grant execute on function private.session_cash(uuid) to authenticated;

create or replace function public.close_register(p_session_id uuid, p_counted_cash bigint, p_note text default null)
returns jsonb
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_staff_id uuid;
  v_store_id uuid;
  v_closed_at timestamptz;
  v_cash record;
  v_voided integer;
begin
  select s.id into v_staff_id from public.staff s where s.user_id = (select auth.uid()) and s.active;
  if v_staff_id is null then
    raise exception 'not allowed' using errcode = '42501';
  end if;
  if p_counted_cash is null or p_counted_cash < 0 then
    raise exception 'counted cash must be zero or more' using errcode = '22023';
  end if;
  if length(p_note) > 300 then
    raise exception 'keep the note under 300 characters' using errcode = '22023';
  end if;

  select r.store_id, rs.closed_at into v_store_id, v_closed_at
  from public.register_sessions rs
  join public.registers r on r.id = rs.register_id
  where rs.id = p_session_id
  for update of rs;
  if not found then
    raise exception 'till not found' using errcode = 'P0002';
  end if;
  if not private.can_access_store(v_store_id) then
    raise exception 'not allowed' using errcode = '42501';
  end if;
  if v_closed_at is not null then
    raise exception 'till is closed' using errcode = 'P0001';
  end if;

  select * into v_cash from private.session_cash(p_session_id);
  select count(*) into v_voided from public.orders o where o.session_id = p_session_id and o.status = 'voided';

  update public.register_sessions set
    closed_by = v_staff_id,
    closed_at = now(),
    counted_cash = p_counted_cash,
    close_note = nullif(trim(p_note), '')
  where id = p_session_id;

  return jsonb_build_object(
    'opening_cash', v_cash.opening_cash,
    'cash_sales', v_cash.cash_sales,
    'cash_refunds', v_cash.cash_refunds,
    'expected_cash', v_cash.expected_cash,
    'counted_cash', p_counted_cash,
    'difference', p_counted_cash - v_cash.expected_cash,
    'voided_count', v_voided
  );
end;

create function public.report_summary(p_store_id uuid, p_from timestamptz, p_to timestamptz)
returns jsonb
language plpgsql
stable
security invoker
set search_path = ''
as $$
#variable_conflict use_column
declare
  v_sales record;
  v_refunds record;
  v_voids record;
  v_methods jsonb;
begin
  perform private.report_guard(p_store_id, p_from, p_to);

  select count(*)::integer as n,
    coalesce(sum(o.subtotal), 0)::bigint as gross,
    coalesce(sum(o.discount_total), 0)::bigint as discounts,
    coalesce(sum(o.tax_total), 0)::bigint as tax,
    coalesce(sum(o.total), 0)::bigint as total
  into v_sales
  from public.orders o
  where o.store_id = p_store_id and o.created_at >= p_from and o.created_at < p_to and o.status <> 'voided';

  select count(*)::integer as n, coalesce(sum(r.total), 0)::bigint as total, coalesce(sum(r.tax_total), 0)::bigint as tax
  into v_refunds
  from public.refunds r
  where r.store_id = p_store_id and r.created_at >= p_from and r.created_at < p_to;

  select count(*)::integer as n, coalesce(sum(o.total), 0)::bigint as total
  into v_voids
  from public.orders o
  where o.store_id = p_store_id and o.voided_at >= p_from and o.voided_at < p_to;

  select jsonb_build_object(
    'cash', coalesce(sum(m.amount) filter (where m.method = 'cash'), 0)::bigint,
    'card', coalesce(sum(m.amount) filter (where m.method = 'card'), 0)::bigint,
    'other', coalesce(sum(m.amount) filter (where m.method = 'other'), 0)::bigint
  )
  into v_methods
  from (
    select p.method, p.amount
    from public.payments p
    join public.orders o on o.id = p.order_id
    where o.store_id = p_store_id and o.created_at >= p_from and o.created_at < p_to and o.status <> 'voided'
    union all
    select rp.method, -rp.amount
    from public.refund_payments rp
    join public.refunds r on r.id = rp.refund_id
    where r.store_id = p_store_id and r.created_at >= p_from and r.created_at < p_to
  ) m;

  return jsonb_build_object(
    'sales_count', v_sales.n,
    'gross', v_sales.gross,
    'discounts', v_sales.discounts,
    'tax', v_sales.tax,
    'sales_total', v_sales.total,
    'refund_count', v_refunds.n,
    'refunds_total', v_refunds.total,
    'refund_tax', v_refunds.tax,
    'net_sales', v_sales.total - v_refunds.total,
    'net_tax', v_sales.tax - v_refunds.tax,
    'average_sale', case when v_sales.n = 0 then 0 else private.div_half_even(v_sales.total, v_sales.n) end,
    'void_count', v_voids.n,
    'void_total', v_voids.total,
    'methods', v_methods
  );
end;
$$;

create function public.report_trend(p_store_id uuid, p_from timestamptz, p_to timestamptz, p_bucket text)
returns table (bucket text, sales_count integer, sales_total bigint, refunds_total bigint, net_sales bigint)
language plpgsql
stable
security invoker
set search_path = ''
as $$
#variable_conflict use_column
declare
  v_tz text;
  v_step interval;
  v_format text;
begin
  perform private.report_guard(p_store_id, p_from, p_to);
  if p_bucket is null or p_bucket not in ('hour', 'day') then
    raise exception 'bucket must be hour or day' using errcode = '22023';
  end if;
  select s.timezone into v_tz from public.stores s where s.id = p_store_id;
  v_step := case when p_bucket = 'hour' then interval '1 hour' else interval '1 day' end;
  v_format := case when p_bucket = 'hour' then 'YYYY-MM-DD HH24:00' else 'YYYY-MM-DD' end;

  return query
  with slots as (
    select to_char(g, v_format) as label
    from generate_series(date_trunc(p_bucket, p_from at time zone v_tz), (p_to at time zone v_tz) - interval '1 second', v_step) g
  ),
  sold as (
    select to_char(date_trunc(p_bucket, o.created_at at time zone v_tz), v_format) as label, count(*)::integer as n, sum(o.total)::bigint as amount
    from public.orders o
    where o.store_id = p_store_id and o.created_at >= p_from and o.created_at < p_to and o.status <> 'voided'
    group by 1
  ),
  back as (
    select to_char(date_trunc(p_bucket, r.created_at at time zone v_tz), v_format) as label, sum(r.total)::bigint as amount
    from public.refunds r
    where r.store_id = p_store_id and r.created_at >= p_from and r.created_at < p_to
    group by 1
  )
  select s.label, coalesce(d.n, 0), coalesce(d.amount, 0)::bigint, coalesce(b.amount, 0)::bigint, (coalesce(d.amount, 0) - coalesce(b.amount, 0))::bigint
  from (select distinct label from slots) s
  left join sold d on d.label = s.label
  left join back b on b.label = s.label
  order by s.label;
end;
$$;

create function public.report_products(p_store_id uuid, p_from timestamptz, p_to timestamptz)
returns table (variant_id uuid, name text, category text, units_sold integer, units_refunded integer, net_units integer, revenue bigint, refunded bigint, net_revenue bigint)
language plpgsql
stable
security invoker
set search_path = ''
as $$
#variable_conflict use_column
begin
  perform private.report_guard(p_store_id, p_from, p_to);

  return query
  with lines as (
    select coalesce(oi.variant_id::text, 'name:' || oi.name) as k, oi.variant_id as vid, oi.name as snap,
      oi.quantity as sold_q, oi.line_total::bigint as sold_a, 0 as back_q, 0::bigint as back_a
    from public.order_items oi
    join public.orders o on o.id = oi.order_id
    where o.store_id = p_store_id and o.created_at >= p_from and o.created_at < p_to and o.status <> 'voided'
    union all
    select coalesce(oi.variant_id::text, 'name:' || oi.name), oi.variant_id, oi.name,
      0, 0::bigint, ri.quantity, ri.amount::bigint
    from public.refund_items ri
    join public.refunds r on r.id = ri.refund_id
    join public.order_items oi on oi.id = ri.order_item_id
    where r.store_id = p_store_id and r.created_at >= p_from and r.created_at < p_to
  ),
  grouped as (
    select l.k, (array_agg(l.vid) filter (where l.vid is not null))[1] as vid, max(l.snap) as snap,
      sum(l.sold_q)::integer as sq, sum(l.sold_a)::bigint as sa, sum(l.back_q)::integer as bq, sum(l.back_a)::bigint as ba
    from lines l
    group by l.k
  )
  select g.vid,
    coalesce(case when v.name = 'Default' then p.name else p.name || ' – ' || v.name end, g.snap),
    c.name,
    g.sq, g.bq, g.sq - g.bq, g.sa, g.ba, g.sa - g.ba
  from grouped g
  left join public.product_variants v on v.id = g.vid
  left join public.products p on p.id = v.product_id
  left join public.categories c on c.id = p.category_id
  order by g.sa - g.ba desc, 2, 1;
end;
$$;

create function public.report_staff(p_store_id uuid, p_from timestamptz, p_to timestamptz)
returns table (staff_id uuid, name text, sales_count integer, sales_total bigint, refund_count integer, refunds_total bigint, void_count integer, void_total bigint, cash_void_count integer, discounts bigint)
language plpgsql
stable
security invoker
set search_path = ''
as $$
#variable_conflict use_column
begin
  perform private.report_guard(p_store_id, p_from, p_to);

  return query
  with sales_by as (
    select o.staff_id as sid, count(*)::integer as n, sum(o.total)::bigint as amount, sum(o.discount_total)::bigint as discount_sum
    from public.orders o
    where o.store_id = p_store_id and o.created_at >= p_from and o.created_at < p_to and o.status <> 'voided'
    group by o.staff_id
  ),
  refunds_by as (
    select r.staff_id as sid, count(*)::integer as n, sum(r.total)::bigint as amount
    from public.refunds r
    where r.store_id = p_store_id and r.created_at >= p_from and r.created_at < p_to
    group by r.staff_id
  ),
  voids_by as (
    select o.staff_id as sid, count(*)::integer as n, sum(o.total)::bigint as amount,
      (count(*) filter (where exists (select 1 from public.payments p where p.order_id = o.id and p.method = 'cash')))::integer as cash
    from public.orders o
    where o.store_id = p_store_id and o.voided_at >= p_from and o.voided_at < p_to
    group by o.staff_id
  ),
  ids as (
    select sid from sales_by union select sid from refunds_by union select sid from voids_by
  )
  select ids.sid, coalesce(st.name, 'Former staff'),
    coalesce(s.n, 0), coalesce(s.amount, 0)::bigint,
    coalesce(r.n, 0), coalesce(r.amount, 0)::bigint,
    coalesce(v.n, 0), coalesce(v.amount, 0)::bigint, coalesce(v.cash, 0),
    coalesce(s.discount_sum, 0)::bigint
  from ids
  left join sales_by s on s.sid = ids.sid
  left join refunds_by r on r.sid = ids.sid
  left join voids_by v on v.sid = ids.sid
  left join public.staff st on st.id = ids.sid
  order by coalesce(s.amount, 0) desc, 2;
end;
$$;

import { nextDay, zonedDayStart } from "@/lib/orders/list";

export type RangePreset = "today" | "yesterday" | "7d" | "30d" | "this-month" | "last-month" | "custom";

export const RANGE_PRESETS: { value: RangePreset; label: string }[] = [
  { value: "today", label: "Today" },
  { value: "yesterday", label: "Yesterday" },
  { value: "7d", label: "Last 7 days" },
  { value: "30d", label: "Last 30 days" },
  { value: "this-month", label: "This month" },
  { value: "last-month", label: "Last month" },
  { value: "custom", label: "Custom" },
];

export type ReportRange = { preset: RangePreset; fromDate: string; toDate: string; from: Date; to: Date; bucket: "hour" | "day"; label: string };

const MAX_DAYS = 366;

function first(value: string | string[] | undefined): string {
  return (Array.isArray(value) ? value[0] : value) ?? "";
}

function isDate(value: string): boolean {
  if (!/^\d{4}-\d{2}-\d{2}$/.test(value)) return false;
  const parsed = new Date(`${value}T00:00:00Z`);
  return !Number.isNaN(parsed.getTime()) && parsed.toISOString().slice(0, 10) === value;
}

export function addDays(date: string, days: number): string {
  const [year, month, day] = date.split("-").map(Number);
  return new Date(Date.UTC(year, month - 1, day + days)).toISOString().slice(0, 10);
}

function daysInclusive(from: string, to: string): number {
  return Math.round((Date.parse(`${to}T00:00:00Z`) - Date.parse(`${from}T00:00:00Z`)) / 86_400_000) + 1;
}

export function localToday(now: Date, timeZone: string): string {
  return new Intl.DateTimeFormat("en-CA", { timeZone, year: "numeric", month: "2-digit", day: "2-digit" }).format(now);
}

function formatDay(date: string): string {
  return new Intl.DateTimeFormat("en", { dateStyle: "medium", timeZone: "UTC" }).format(new Date(`${date}T00:00:00Z`));
}

function build(preset: RangePreset, fromDate: string, toDate: string, timeZone: string): ReportRange {
  const label =
    preset === "custom"
      ? fromDate === toDate
        ? formatDay(fromDate)
        : `${formatDay(fromDate)} – ${formatDay(toDate)}`
      : (RANGE_PRESETS.find((entry) => entry.value === preset)?.label ?? "Today");
  return {
    preset,
    fromDate,
    toDate,
    from: zonedDayStart(fromDate, timeZone),
    to: zonedDayStart(nextDay(toDate), timeZone),
    bucket: fromDate === toDate ? "hour" : "day",
    label,
  };
}

export function resolveRange(
  params: Record<string, string | string[] | undefined>,
  timeZone: string,
  now: Date,
): { range: ReportRange; error: string | null } {
  const today = localToday(now, timeZone);
  const fallback = build("today", today, today, timeZone);
  switch (first(params.range)) {
    case "yesterday":
      return { range: build("yesterday", addDays(today, -1), addDays(today, -1), timeZone), error: null };
    case "7d":
      return { range: build("7d", addDays(today, -6), today, timeZone), error: null };
    case "30d":
      return { range: build("30d", addDays(today, -29), today, timeZone), error: null };
    case "this-month":
      return { range: build("this-month", `${today.slice(0, 7)}-01`, today, timeZone), error: null };
    case "last-month": {
      const lastOfPrevious = addDays(`${today.slice(0, 7)}-01`, -1);
      return { range: build("last-month", `${lastOfPrevious.slice(0, 7)}-01`, lastOfPrevious, timeZone), error: null };
    }
    case "custom": {
      const from = first(params.from);
      const to = first(params.to);
      if (!isDate(from) || !isDate(to)) return { range: fallback, error: null };
      if (from > to) return { range: fallback, error: "The start date is after the end date." };
      if (daysInclusive(from, to) > MAX_DAYS) return { range: fallback, error: "Pick a range of up to 366 days." };
      return { range: build("custom", from, to, timeZone), error: null };
    }
    default:
      return { range: fallback, error: null };
  }
}

export type StaffFlag = { rule: "voids" | "refunds" | "cash-void"; label: string };

function percent(value: number): string {
  return (value * 100).toFixed(1);
}

export function staffFlags(row: StaffReportRow): StaffFlag[] {
  const flags: StaffFlag[] = [];
  const voidShare = row.void_count / Math.max(1, row.sales_count + row.void_count);
  if (row.void_count >= 2 && voidShare > 0.03) flags.push({ rule: "voids", label: `Voids ${row.void_count} (${percent(voidShare)}%)` });
  if (row.refund_count >= 2) {
    if (row.sales_total <= 0 && row.refunds_total > 0) flags.push({ rule: "refunds", label: "Refunds with no sales" });
    else if (row.sales_total > 0 && row.refunds_total / row.sales_total > 0.05) {
      flags.push({ rule: "refunds", label: `Refunds ${percent(row.refunds_total / row.sales_total)}% of sales` });
    }
  }
  if (row.cash_void_count >= 1) {
    flags.push({ rule: "cash-void", label: row.cash_void_count === 1 ? "Voided a cash sale" : `Voided ${row.cash_void_count} cash sales` });
  }
  return flags;
}

export function categoryShares(rows: ProductReportRow[]): { category: string; netRevenue: number; share: number }[] {
  const totals = new Map<string, number>();
  for (const row of rows) {
    const category = row.category ?? "Uncategorised";
    totals.set(category, (totals.get(category) ?? 0) + row.net_revenue);
  }
  const positive = [...totals.values()].reduce((sum, value) => sum + Math.max(0, value), 0);
  return [...totals.entries()]
    .map(([category, netRevenue]) => ({ category, netRevenue, share: positive > 0 ? Math.round((Math.max(0, netRevenue) / positive) * 1000) / 10 : 0 }))
    .sort((a, b) => b.netRevenue - a.netRevenue || a.category.localeCompare(b.category));
}

export function sortProducts(rows: ProductReportRow[], sort: "revenue" | "units"): ProductReportRow[] {
  return [...rows].sort((a, b) =>
    sort === "units" ? b.net_units - a.net_units || b.net_revenue - a.net_revenue : b.net_revenue - a.net_revenue || b.net_units - a.net_units,
  );
}

export function trendBars(points: TrendPoint[]): { bucket: string; net: number; height: number; negative: boolean }[] {
  const max = Math.max(0, ...points.map((point) => Math.abs(point.net_sales)));
  return points.map((point) => ({
    bucket: point.bucket,
    net: point.net_sales,
    height: max === 0 ? 0 : Math.round((Math.abs(point.net_sales) / max) * 100),
    negative: point.net_sales < 0,
  }));
}

export function tickLabel(bucket: string, kind: "hour" | "day"): string {
  if (kind === "hour") return bucket.slice(11, 13);
  return new Intl.DateTimeFormat("en", { month: "short", day: "numeric", timeZone: "UTC" }).format(new Date(`${bucket}T00:00:00Z`));
}

export function differenceLabel(difference: number, money: (minor: number) => string): { text: string; tone: "short" | "over" | "balanced" } {
  if (difference < 0) return { text: `Short ${money(-difference)}`, tone: "short" };
  if (difference > 0) return { text: `Over ${money(difference)}`, tone: "over" };
  return { text: "Balanced", tone: "balanced" };
}

import { resolveRange } from "@/lib/reports/range";
import { exportHref, parseOnlyOff, parseProductSort, parseReportTab, reportHref } from "@/lib/reports/params";
import { categoryShares, sortProducts } from "@/lib/reports/shape";
import { loadCashups, loadProducts, loadStaff, loadSummary, loadTrend } from "@/lib/reports/queries";

export const metadata: Metadata = { title: "Reports" };

const PAGE_SIZE = 50;

type ReportsPageProps = { searchParams: Promise<Record<string, string | string[] | undefined>> };

export default async function ReportsPage({ searchParams }: ReportsPageProps) {
  const staff = await requireRole("manager");
  const store = await getCurrentStore(staff);
  if (!store) {
    return (
      <section id="reports" className="flex min-h-0 min-w-0 flex-1 flex-col">
        <PageHeader title="Reports" />
        <EmptyState title="No store yet" description="Ask an owner to add you to a store." />
      </section>
    );
  }

  const params = await searchParams;
  const supabase = await createClient();
  const { data: storeRow } = await supabase.from("stores").select("timezone").eq("id", store.id).maybeSingle();
  const timeZone = storeRow?.timezone ?? "UTC";
  const { range, error } = resolveRange(params, timeZone, new Date());
  const tab = parseReportTab(params);
  const money = (minor: number) => formatMoney(minor, store.currency, "en-US");
  const today = resolveRange({}, timeZone, new Date()).range;

  let content: ReactNode;
  if (error) {
    content = <EmptyState title="Can't show that range" description={error} action={<Button href={reportHref(tab, today)} variant="secondary" size="md">Show today</Button>} />;
  } else if (tab === "summary") {
    const [summary, trend] = await Promise.all([loadSummary(supabase, store.id, range), loadTrend(supabase, store.id, range)]);
    content =
      summary.sales_count === 0 && summary.refund_count === 0 && summary.void_count === 0 ? (
        <EmptyState
          title="No sales in this range"
          description="Sales, refunds and voids from the register show up here."
          action={range.preset === "today" ? undefined : <Button href={reportHref(tab, today)} variant="secondary" size="md">Show today</Button>}
        />
      ) : (
        <SummaryView summary={summary} trend={trend} range={range} money={money} />
      );
  } else if (tab === "products") {
    const sort = parseProductSort(params);
    const rows = sortProducts(await loadProducts(supabase, store.id, range), sort);
    const requested = Number.parseInt(String(params.page ?? "1"), 10);
    const paged = pageOf(rows, Number.isFinite(requested) && requested > 0 ? requested : 1, PAGE_SIZE);
    content =
      rows.length === 0 ? (
        <EmptyState title="Nothing sold in this range" description="Try a longer range." />
      ) : (
        <ProductsView
          rows={paged.rows}
          categories={categoryShares(rows)}
          sort={sort}
          page={paged.page}
          pages={paged.pages}
          total={paged.total}
          money={money}
          sortHref={(value) => reportHref("products", range, { sort: value })}
          hrefFor={(page) => reportHref("products", range, { sort, page: String(page) })}
        />
      );
  } else if (tab === "staff") {
    const rows = await loadStaff(supabase, store.id, range);
    content = rows.length === 0 ? <EmptyState title="No staff activity in this range" description="Try a longer range." /> : <StaffView rows={rows} range={range} money={money} />;
  } else {
    const onlyOff = parseOnlyOff(params);
    const rows = (await loadCashups(supabase, store.id, range)).filter((row) => !onlyOff || row.difference !== 0);
    content = (
      <CashupsView
        rows={rows}
        onlyOff={onlyOff}
        toggleHref={reportHref("cashups", range, onlyOff ? {} : { only: "off" })}
        timeZone={timeZone}
        money={money}
      />
    );
  }

  return (
    <section id="reports" className="flex min-h-0 min-w-0 flex-1 flex-col">
      <PageHeader
        title={`Reports · ${store.name}`}
        actions={
          <a href={exportHref(tab, range)} className={buttonVariants({ variant: "secondary", size: "md" })}>
            Export CSV
          </a>
        }
      />
      <ReportsToolbar tab={tab} preset={range.preset} fromDate={range.fromDate} toDate={range.toDate} />
      <ScrollArea className="min-h-0 flex-1">{content}</ScrollArea>
    </section>
  );
}

import { NextResponse, type NextRequest } from "next/server";
import { getCurrentStaff, getCurrentStore } from "@/lib/auth/staff";
import { roleAtLeast } from "@/lib/auth/roles";
import { createClient } from "@/lib/supabase/server";
import { toCsv, type CsvCell } from "@/lib/csv";
import { resolveRange } from "@/lib/reports/range";
import { parseReportTab } from "@/lib/reports/params";
import { sortProducts } from "@/lib/reports/shape";
import { cashupsCsv, productsCsv, staffCsv, summaryCsv } from "@/lib/reports/csv";
import { loadCashups, loadProducts, loadStaff, loadSummary } from "@/lib/reports/queries";

export async function GET(request: NextRequest) {
  const staff = await getCurrentStaff();
  if (!staff || !roleAtLeast(staff.role, "manager")) return new NextResponse("Not found", { status: 404 });
  const store = await getCurrentStore(staff);
  if (!store) return new NextResponse("Not found", { status: 404 });

  const params = Object.fromEntries(request.nextUrl.searchParams);
  const supabase = await createClient();
  const { data: storeRow } = await supabase.from("stores").select("timezone").eq("id", store.id).maybeSingle();
  const timeZone = storeRow?.timezone ?? "UTC";
  const { range, error } = resolveRange(params, timeZone, new Date());
  if (error) return new NextResponse(error, { status: 400 });
  const tab = parseReportTab(params);

  let rows: CsvCell[][];
  if (tab === "products") rows = productsCsv(sortProducts(await loadProducts(supabase, store.id, range), "revenue"), store.currency);
  else if (tab === "staff") rows = staffCsv(await loadStaff(supabase, store.id, range), store.currency);
  else if (tab === "cashups") rows = cashupsCsv(await loadCashups(supabase, store.id, range), store.currency, timeZone);
  else rows = summaryCsv(await loadSummary(supabase, store.id, range), store.currency);

  return new NextResponse(`﻿${toCsv(rows)}`, {
    headers: {
      "Content-Type": "text/csv; charset=utf-8",
      "Content-Disposition": `attachment; filename="${tab}-${range.fromDate}-to-${range.toDate}.csv"`,
      "Cache-Control": "private, no-store",
    },
  });
}
```

## Reports

Managers and owners get reports for the store picked in the sidebar, for today, yesterday, the last 7 or 30 days, this or last month, or any range up to a year. Days and hours follow the store's time zone.

- **Summary:** net sales, number of sales, average sale, refunds, discounts and tax. It also shows a sales chart by hour or day, a cash/card/other split, and voided sales.
- **Products:** best sellers by net revenue or units, with refunds taken off, and each category's share.
- **Staff:** sales, refunds, voids and discounts per person. Voids above 3%, refunds above 5% of sales, and any voided cash sale are flagged.
- **Cash-ups:** every closed till, with its float, cash sales, cash refunds, expected and counted cash, and whether it was short or over.
- **CSV export** of whichever report you're looking at.

Refunds count on the day they happen, and voided sales never count, so a day's report matches its tills and doesn't change later.
```
