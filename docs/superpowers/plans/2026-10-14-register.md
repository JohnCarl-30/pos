# Register (Checkout) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (the user prefers inline building) or superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give cashiers a touch-friendly till with:
- till sessions with a cash count;
- discounts with a cashier limit and manager approval;
- cash, card and split payments;
- printed receipts;
- attached customers;
- out-of-stock warnings.

Every total is computed by the database.

**Architecture:**
- **Pricing.** Cart pricing lives in two mirrored places:
  - `lib/checkout.ts`, which gives the live total on screen;
  - `private.price_cart` in Postgres, which is authoritative.

  One JSON file of test carts drives both a Vitest suite and a generated pgTAP file, so they can't drift.
- **Writing a sale.** `public.create_order` (security definer) is the only way to write a sale. It:
  - reprices from the catalog;
  - enforces the discount authority;
  - checks payments;
  - takes the next receipt number;
  - writes the order, items, payments and `sold` stock movements in one transaction.

  Direct inserts on the sale tables are revoked.
- **Manager approval.** A server action checks a manager's credentials with a throwaway client, then writes a single-use `discount_approvals` row using the service-role client.

**Tech Stack:** Next.js 16.4, React 19, Supabase (Postgres 17, RLS, pgTAP), zod 4, Vitest, Playwright, Tailwind 4.

## Review Focus

1. **Screen and database disagree on a total.** The cashier tells the customer one amount and the database records another. Pinned by the shared vectors (Tasks 1–2).
2. **A tampered request records a cheaper sale.** This covers fake prices, a discount over the limit without approval, a reused approval, or a direct insert. Pinned by the `register.test.sql` assertions (Task 2).
3. **Two sales on one register get the same receipt number, or a failed sale skips one.** Pinned by the receipt-sequence assertion (Task 2).
4. **Closing the till reports the wrong expected cash**, for example by counting change as cash taken. Pinned by the `close_register` assertion (Task 2).
5. **A cashier ends up with the till locked to another store's register.** This can happen after switching store in the sidebar. Pinned by `pickRegister` tests and the store check in `selectRegister` (Task 3).

```ts
import { calculateLine, divRoundHalfEven } from "./tax";

export type CartLineInput = { price: number; quantity: number; rateBps: number; discountBps?: number | null; discountAmount?: number | null };
export type OrderDiscountInput = { bps?: number | null; amount?: number | null } | null;
export type PricedLine = { discount: number; tax: number; lineTotal: number };
export type PricedCart = { subtotal: number; discountTotal: number; taxTotal: number; total: number; lines: PricedLine[] };
export type CheckoutVector = { name: string; pricesIncludeTax: boolean; lines: CartLineInput[]; orderDiscount: OrderDiscountInput; expected: PricedCart };
export type PaymentMethod = "cash" | "card" | "other";
export type PaymentInput = { method: PaymentMethod; amount: number; tendered?: number | null; reference?: string | null };
export type PaymentSummary = { paid: number; remaining: number; change: number; complete: boolean; error: string | null };

export class CartError extends Error {}

function discountFrom(base: number, bps: number | null | undefined, amount: number | null | undefined): number {
  if (bps !== null && bps !== undefined && amount !== null && amount !== undefined) throw new CartError("Choose a percentage or an amount, not both");
  if (bps !== null && bps !== undefined) {
    if (!Number.isInteger(bps) || bps < 0 || bps > 10_000) throw new CartError("A percentage must be between 0 and 100");
    return Number(divRoundHalfEven(BigInt(base) * BigInt(bps), 10_000n));
  }
  if (amount !== null && amount !== undefined) {
    if (!Number.isSafeInteger(amount) || amount < 0 || amount > base) throw new CartError("A discount can't be more than the amount it applies to");
    return amount;
  }
  return 0;
}

export function allocate(amount: number, bases: number[]): number[] {
  const total = bases.reduce((sum, value) => sum + value, 0);
  if (amount === 0 || total === 0) return bases.map(() => 0);
  const big = BigInt(amount);
  const bigTotal = BigInt(total);
  const shares = bases.map((base) => (big * BigInt(base)) / bigTotal);
  const remainders = bases.map((base) => (big * BigInt(base)) % bigTotal);
  let left = big - shares.reduce((sum, value) => sum + value, 0n);
  const order = bases.map((_, index) => index).sort((a, b) => (remainders[b] > remainders[a] ? 1 : remainders[b] < remainders[a] ? -1 : a - b));
  for (const index of order) {
    if (left === 0n) break;
    shares[index] += 1n;
    left -= 1n;
  }
  return shares.map(Number);
}

export function priceCart(lines: CartLineInput[], orderDiscount: OrderDiscountInput, pricesIncludeTax: boolean): PricedCart {
  const gross = lines.map((line) => {
    if (!Number.isSafeInteger(line.price) || line.price < 0) throw new CartError("Prices must be whole minor units");
    if (!Number.isInteger(line.quantity) || line.quantity < 1 || line.quantity > 9_999) throw new CartError("Quantity must be between 1 and 9999");
    return line.price * line.quantity;
  });
  const lineDiscounts = lines.map((line, index) => discountFrom(gross[index], line.discountBps, line.discountAmount));
  const bases = gross.map((value, index) => value - lineDiscounts[index]);
  const afterLines = bases.reduce((sum, value) => sum + value, 0);
  const orderAmount = orderDiscount ? discountFrom(afterLines, orderDiscount.bps, orderDiscount.amount) : 0;
  const allocations = allocate(orderAmount, bases);

  const priced = lines.map((line, index) => {
    const amount = bases[index] - allocations[index];
    const totals = calculateLine({ unitPrice: amount, quantity: 1, discount: 0, rateBps: line.rateBps, pricesIncludeTax });
    return { discount: lineDiscounts[index] + allocations[index], tax: totals.tax, lineTotal: totals.gross };
  });

  return {
    subtotal: gross.reduce((sum, value) => sum + value, 0),
    discountTotal: priced.reduce((sum, line) => sum + line.discount, 0),
    taxTotal: priced.reduce((sum, line) => sum + line.tax, 0),
    total: priced.reduce((sum, line) => sum + line.lineTotal, 0),
    lines: priced,
  };
}

export function discountShareBps(subtotal: number, discountTotal: number): number {
  if (subtotal <= 0 || discountTotal <= 0) return 0;
  const numerator = BigInt(discountTotal) * 10_000n;
  const denominator = BigInt(subtotal);
  return Number((numerator + denominator - 1n) / denominator);
}

export function summarisePayments(total: number, payments: PaymentInput[]): PaymentSummary {
  let paid = 0;
  let change = 0;
  let error: string | null = null;
  for (const payment of payments) {
    if (!Number.isSafeInteger(payment.amount) || payment.amount <= 0) error ??= "Each payment needs an amount above 0";
    if (payment.tendered !== null && payment.tendered !== undefined) {
      if (payment.method !== "cash") error ??= "Only cash can have an amount received";
      else if (payment.tendered < payment.amount) error ??= "Cash received can't be less than the amount";
      else change += payment.tendered - payment.amount;
    }
    if (payment.reference && payment.reference.length > 100) error ??= "Keep the reference under 100 characters";
    paid += Number.isSafeInteger(payment.amount) ? payment.amount : 0;
  }
  if (paid > total) error ??= "Payments add up to more than the total";
  return { paid, remaining: Math.max(0, total - paid), change, complete: error === null && paid === total, error };
}
```

```ts
import type { CheckoutVector } from "./checkout";

function sqlString(value: string): string {
  return `'${value.replace(/'/g, "''")}'`;
}

export function vectorsToSql(vectors: CheckoutVector[]): string {
  const lines = ["begin;", "create extension if not exists pgtap with schema extensions;", `select plan(${vectors.length});`, ""];
  for (const vector of vectors) {
    const input = JSON.stringify(
      vector.lines.map((line) => ({
        price: line.price,
        quantity: line.quantity,
        rate_bps: line.rateBps,
        discount_bps: line.discountBps ?? null,
        discount_amount: line.discountAmount ?? null,
      })),
    );
    const discount = vector.orderDiscount ? `'${JSON.stringify({ bps: vector.orderDiscount.bps ?? null, amount: vector.orderDiscount.amount ?? null })}'::jsonb` : "null";
    const expected = JSON.stringify({
      subtotal: vector.expected.subtotal,
      discount_total: vector.expected.discountTotal,
      tax_total: vector.expected.taxTotal,
      total: vector.expected.total,
      lines: vector.expected.lines.map((line) => ({ discount: line.discount, tax: line.tax, line_total: line.lineTotal })),
    });
    lines.push(`select is(private.price_cart(${vector.pricesIncludeTax}, '${input}'::jsonb, ${discount}), '${expected}'::jsonb, ${sqlString(vector.name)});`);
  }
  lines.push("", "select * from finish();", "rollback;", "");
  return lines.join("\n");
}
```

```sql
create function private.div_half_even(p_num numeric, p_den numeric)
returns bigint
language sql
immutable
set search_path = ''
as $$
  select (case
    when parts.r * 2 > p_den then parts.q + 1
    when parts.r * 2 < p_den then parts.q
    when mod(parts.q, 2) = 0 then parts.q
    else parts.q + 1
  end)::bigint
  from (select floor(p_num / p_den) as q, p_num - floor(p_num / p_den) * p_den as r) as parts
$$;

create function private.price_cart(p_include_tax boolean, p_lines jsonb, p_order_discount jsonb)
returns jsonb
language plpgsql
immutable
set search_path = ''
as $$
declare
  v_count integer := coalesce(jsonb_array_length(p_lines), 0);
  v_gross bigint[] := '{}';
  v_disc bigint[] := '{}';
  v_rate integer[] := '{}';
  v_alloc bigint[] := '{}';
  v_rem numeric[] := '{}';
  v_order_index integer[];
  v_line jsonb;
  v_bps integer;
  v_amount bigint;
  v_line_gross bigint;
  v_line_disc bigint;
  v_after bigint := 0;
  v_order bigint := 0;
  v_alloc_sum bigint := 0;
  v_left bigint;
  v_net bigint;
  v_tax bigint;
  v_line_total bigint;
  v_subtotal bigint := 0;
  v_discount_total bigint := 0;
  v_tax_total bigint := 0;
  v_total bigint := 0;
  v_out jsonb := '[]'::jsonb;
  i integer;
begin
  for i in 1..v_count loop
    v_line := p_lines -> (i - 1);
    v_line_gross := (v_line ->> 'price')::bigint * (v_line ->> 'quantity')::integer;
    v_bps := (v_line ->> 'discount_bps')::integer;
    v_amount := (v_line ->> 'discount_amount')::bigint;
    if v_bps is not null and v_amount is not null then
      raise exception 'choose a percentage or an amount, not both' using errcode = '22023';
    elsif v_bps is not null then
      if v_bps < 0 or v_bps > 10000 then
        raise exception 'a percentage must be between 0 and 100' using errcode = '22023';
      end if;
      v_line_disc := private.div_half_even(v_line_gross::numeric * v_bps, 10000);
    elsif v_amount is not null then
      if v_amount < 0 or v_amount > v_line_gross then
        raise exception 'a discount can''t be more than the amount it applies to' using errcode = '22023';
      end if;
      v_line_disc := v_amount;
    else
      v_line_disc := 0;
    end if;
    v_gross := v_gross || v_line_gross;
    v_disc := v_disc || v_line_disc;
    v_rate := v_rate || coalesce((v_line ->> 'rate_bps')::integer, 0);
    v_subtotal := v_subtotal + v_line_gross;
    v_after := v_after + v_line_gross - v_line_disc;
  end loop;

  if p_order_discount is not null and jsonb_typeof(p_order_discount) = 'object' then
    v_bps := (p_order_discount ->> 'bps')::integer;
    v_amount := (p_order_discount ->> 'amount')::bigint;
    if v_bps is not null and v_amount is not null then
      raise exception 'choose a percentage or an amount, not both' using errcode = '22023';
    elsif v_bps is not null then
      if v_bps < 0 or v_bps > 10000 then
        raise exception 'a percentage must be between 0 and 100' using errcode = '22023';
      end if;
      v_order := private.div_half_even(v_after::numeric * v_bps, 10000);
    elsif v_amount is not null then
      if v_amount < 0 or v_amount > v_after then
        raise exception 'a discount can''t be more than the amount it applies to' using errcode = '22023';
      end if;
      v_order := v_amount;
    end if;
  end if;

  for i in 1..v_count loop
    if v_after = 0 or v_order = 0 then
      v_alloc := v_alloc || 0::bigint;
      v_rem := v_rem || 0::numeric;
    else
      v_alloc := v_alloc || floor(v_order::numeric * (v_gross[i] - v_disc[i]) / v_after)::bigint;
      v_rem := v_rem || mod(v_order::numeric * (v_gross[i] - v_disc[i]), v_after::numeric);
      v_alloc_sum := v_alloc_sum + v_alloc[i];
    end if;
  end loop;

  if v_left > 0 then
    select array_agg(t.idx::integer order by t.rem desc, t.idx) into v_order_index
    from unnest(v_rem) with ordinality as t(rem, idx);
    for i in 1..v_left loop
      v_alloc[v_order_index[i]] := v_alloc[v_order_index[i]] + 1;
    end loop;
  end if;

  for i in 1..v_count loop
    v_net := v_gross[i] - v_disc[i] - v_alloc[i];
    if p_include_tax then
      v_tax := v_net - private.div_half_even(v_net::numeric * 10000, 10000 + v_rate[i]);
      v_line_total := v_net;
    else
      v_tax := private.div_half_even(v_net::numeric * v_rate[i], 10000);

    end if;
    v_discount_total := v_discount_total + v_disc[i] + v_alloc[i];
    v_tax_total := v_tax_total + v_tax;
    v_total := v_total + v_line_total;

    'discount_total', v_discount_total,
    'tax_total', v_tax_total,
    'total', v_total,
    'lines', v_out

    'cash_sales', v_cash,
```

```ts
import type { CartLineInput, OrderDiscountInput } from "@/lib/checkout";

export type RegisterVariant = { id: string; name: string; sku: string; barcode: string | null; price: number; rateBps: number; track: boolean; quantity: number };
export type RegisterProduct = { id: string; name: string; categoryId: string | null; variants: RegisterVariant[] };
export type RegisterCatalogRow = {
  id: string;
  name: string;
  active: boolean;
  category_id: string | null;
  tax_class_id: string;
  product_variants: {
    id: string;
    name: string;
    sku: string;
    barcode: string | null;
    price: number;
    active: boolean;
    sort_order: number;
    stock_levels: { store_id: string; quantity: number; track: boolean }[];
  }[];
};
export type CartLine = {
  variantId: string;
  label: string;
  sku: string;
  price: number;
  rateBps: number;
  track: boolean;
  stock: number;
  quantity: number;
  discountBps: number | null;
  discountAmount: number | null;
};
export type Discount = { bps: number } | { amount: number } | null;

export function toRegisterCatalog(rows: RegisterCatalogRow[], storeId: string, rates: { tax_class_id: string; rate_bps: number }[]): RegisterProduct[] {
  const rateFor = new Map(rates.map((rate) => [rate.tax_class_id, rate.rate_bps]));
  return rows
    .filter((row) => row.active)
    .map((row) => ({
      id: row.id,
      name: row.name,
      categoryId: row.category_id,
      variants: row.product_variants
        .filter((variant) => variant.active)
        .sort((a, b) => a.sort_order - b.sort_order)
        .map((variant) => {
          const level = variant.stock_levels.find((entry) => entry.store_id === storeId);
          return {
            id: variant.id,
            name: variant.name,
            sku: variant.sku,
            barcode: variant.barcode,
            price: variant.price,
            rateBps: rateFor.get(row.tax_class_id) ?? 0,
            track: level?.track ?? false,
            quantity: level?.quantity ?? 0,
          };
        }),
    }))
    .filter((product) => product.variants.length > 0)
    .sort((a, b) => a.name.localeCompare(b.name));
}

export function findByCode(products: RegisterProduct[], code: string): { product: RegisterProduct; variant: RegisterVariant } | null {
  const trimmed = code.trim();
  if (!trimmed) return null;
  for (const product of products) {
    for (const variant of product.variants) {
      if (variant.barcode === trimmed || variant.sku.toLowerCase() === trimmed.toLowerCase()) return { product, variant };
    }
  }
  return null;
}

export function searchProducts(products: RegisterProduct[], query: string, categoryId: string): RegisterProduct[] {
  const needle = query.trim().toLowerCase();
  return products.filter(
    (product) =>
      (!categoryId || product.categoryId === categoryId) &&
      (!needle || product.name.toLowerCase().includes(needle) || product.variants.some((variant) => variant.sku.toLowerCase().includes(needle))),
  );
}

export function variantLabel(product: RegisterProduct, variant: RegisterVariant): string {
  return variant.name === "Default" ? product.name : `${product.name} – ${variant.name}`;
}

export function addToCart(lines: CartLine[], product: RegisterProduct, variant: RegisterVariant): CartLine[] {
  if (lines.some((line) => line.variantId === variant.id)) {
    return lines.map((line) => (line.variantId === variant.id ? { ...line, quantity: Math.min(9_999, line.quantity + 1) } : line));
  }
  return [
    ...lines,
    {
      variantId: variant.id,
      label: variantLabel(product, variant),
      sku: variant.sku,
      price: variant.price,
      rateBps: variant.rateBps,
      track: variant.track,
      stock: variant.quantity,
      quantity: 1,
      discountBps: null,
      discountAmount: null,
    },
  ];
}

export function setQuantity(lines: CartLine[], variantId: string, quantity: number): CartLine[] {
  if (quantity <= 0) return lines.filter((line) => line.variantId !== variantId);
  return lines.map((line) => (line.variantId === variantId ? { ...line, quantity: Math.min(9_999, Math.floor(quantity)) } : line));
}

export function setLineDiscount(lines: CartLine[], variantId: string, discount: Discount): CartLine[] {
  return lines.map((line) =>
    line.variantId === variantId
      ? {
          ...line,
          discountBps: discount && "bps" in discount ? discount.bps : null,
          discountAmount: discount && "amount" in discount ? discount.amount : null,
        }
      : line,
  );
}

export function cartInputs(lines: CartLine[]): CartLineInput[] {
  return lines.map((line) => ({ price: line.price, quantity: line.quantity, rateBps: line.rateBps, discountBps: line.discountBps, discountAmount: line.discountAmount }));
}

export function isOverStock(line: CartLine): boolean {
  return line.track && line.quantity > line.stock;
}

export function discountInput(discount: Discount): OrderDiscountInput {
  if (!discount) return null;
  return "bps" in discount ? { bps: discount.bps } : { amount: discount.amount };
}
```

```ts
const MESSAGES: [string, string][] = [
  ["till is closed", "This till is closed. Open it again to keep selling."],

  ["item not available", "An item in the cart is no longer for sale. Remove it and try again."],
```

```tsx
type DiscountDialogProps = {

  title: string;
  current: Discount;
  currency: string;

  onApply: (discount: Discount) => void;

function DiscountForm({ title, current, currency, onApply }: Omit<DiscountDialogProps, "open" | "onOpenChange">) {
  const [mode, setMode] = useState<"percent" | "amount">(current && "amount" in current ? "amount" : "percent");
  const [value, setValue] = useState(current ? ("bps" in current ? formatBpsAsPercent(current.bps) : formatAmount(current.amount, currency)) : "");
  const [error, setError] = useState<string | null>(null);

  function submit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    if (value.trim() === "") return onApply(null);
    if (mode === "percent") {
      const bps = parsePercentToBps(value);
      if (bps === null || bps > 10_000) return setError("Enter a percentage from 0 to 100, like 10");
      return onApply(bps === 0 ? null : { bps });
    }
    const amount = parseMoney(value, currency);
    if (amount === null || amount < 0) return setError("Enter an amount like 2.50");
    return onApply(amount === 0 ? null : { amount });
  }

  return (
    <form onSubmit={submit} className="flex flex-col gap-4 p-6">
      <DialogHeader>
        <DialogTitle>{title}</DialogTitle>
        <DialogDescription>Leave it empty to remove the discount.</DialogDescription>
      </DialogHeader>

        <Button variant="secondary" size="md" className="min-h-11 aria-pressed:bg-white/10" aria-pressed={mode === "percent"} onClick={() => setMode("percent")}>
          Percent
        </Button>
        <Button variant="secondary" size="md" className="min-h-11 aria-pressed:bg-white/10" aria-pressed={mode === "amount"} onClick={() => setMode("amount")}>
          Amount
        </Button>

      </Field>
      <DialogFooter>
        {current && (
          <Button variant="ghost" size="md" className="min-h-11" onClick={() => onApply(null)}>
            Remove discount
          </Button>
        )}
        <Button type="submit" variant="primary" size="md" className="min-h-11">
          Apply
        </Button>
      </DialogFooter>
    </form>
  );
```

```tsx
import { Input } from "@/components/_ui/input";
import { Label } from "@/components/_ui/label";
import { Dialog, DialogContent, DialogDescription, DialogHeader, DialogTitle } from "@/components/_ui/dialog";
import { summarisePayments, type PaymentInput, type PaymentMethod } from "@/lib/checkout";
import { formatAmount, parseMoney } from "@/lib/money";

type PayDialogProps = {
  open: boolean;
  total: number;
  currency: string;
  offline: boolean;
  money: (minor: number) => string;
  onOpenChange: (open: boolean) => void;
  onComplete: (payments: PaymentInput[]) => Promise<string | null>;
};

type Row = { key: number; method: PaymentMethod; amount: string; tendered: string; reference: string };

const METHOD_LABELS: Record<PaymentMethod, string> = { cash: "Cash", card: "Card", other: "Other" };

function PayForm({ total, currency, offline, money, onComplete }: Omit<PayDialogProps, "open" | "onOpenChange">) {
  const [rows, setRows] = useState<Row[]>([]);
  const [nextKey, setNextKey] = useState(1);
  const [error, setError] = useState<string | null>(null);
  const [pending, setPending] = useState(false);

  let parseError: string | null = null;
  const payments: PaymentInput[] = rows.map((row) => {
    const amount = parseMoney(row.amount, currency);
    if (amount === null) parseError ??= `Enter the ${METHOD_LABELS[row.method].toLowerCase()} amount, like 5.00`;
    const tendered = row.method === "cash" && row.tendered.trim() !== "" ? parseMoney(row.tendered, currency) : null;
    if (row.method === "cash" && row.tendered.trim() !== "" && tendered === null) parseError ??= "Enter the cash received, like 20.00";
    return { method: row.method, amount: amount ?? 0, tendered, reference: row.reference.trim() || null };
  });
  const summary = summarisePayments(total, payments);
  const message = error ?? parseError ?? summary.error;

  function add(method: PaymentMethod) {
    setRows((current) => [...current, { key: nextKey, method, amount: formatAmount(summary.remaining, currency), tendered: "", reference: "" }]);
    setNextKey((key) => key + 1);
    setError(null);
  }

  function update(key: number, patch: Partial<Row>) {
    setRows((current) => current.map((row) => (row.key === key ? { ...row, ...patch } : row)));
    setError(null);
  }

  async function complete() {
    setPending(true);
    const result = await onComplete(payments);
    setPending(false);
    if (result) setError(result);
  }

  return (
    <div className="flex flex-col gap-4 p-6">
      <DialogHeader>
        <DialogTitle>Take payment</DialogTitle>
        <DialogDescription>Total {money(total)}</DialogDescription>
      </DialogHeader>
      <div className="grid grid-cols-3 gap-2">
        {(["cash", "card", "other"] as PaymentMethod[]).map((method) => (
          <Button key={method} variant="secondary" size="md" className="min-h-11" disabled={summary.remaining === 0} onClick={() => add(method)}>
            {METHOD_LABELS[method]}
          </Button>
        ))}
      </div>
      <ul className="flex flex-col gap-3">
        {rows.map((row) => (
          <li key={row.key} className="border-line-strong flex flex-col gap-2 rounded-lg border p-3">
            <div className="flex items-center justify-between gap-2">
              <span className="lead-style">{METHOD_LABELS[row.method]}</span>
              <Button variant="ghost" size="md" className="min-h-11" onClick={() => setRows((current) => current.filter((entry) => entry.key !== row.key))}>
                Remove
              </Button>
            </div>
            <Label htmlFor={`pay-amount-${row.key}`}>{`${METHOD_LABELS[row.method]} amount`}</Label>
            <Input id={`pay-amount-${row.key}`} inputMode="decimal" className="min-h-11" value={row.amount} onChange={(event) => update(row.key, { amount: event.target.value })} />
            {row.method === "cash" ? (
              <>
                <Label htmlFor={`pay-tendered-${row.key}`}>Cash received</Label>
                <div className="flex gap-2">
                  <Input id={`pay-tendered-${row.key}`} inputMode="decimal" className="min-h-11" placeholder="Optional" value={row.tendered} onChange={(event) => update(row.key, { tendered: event.target.value })} />
                  <Button variant="secondary" size="md" className="min-h-11" onClick={() => update(row.key, { tendered: row.amount })}>
                    Exact
                  </Button>
                </div>
              </>
            ) : (
              <>
                <Label htmlFor={`pay-reference-${row.key}`}>Reference (optional)</Label>
                <Input id={`pay-reference-${row.key}`} className="min-h-11" maxLength={100} value={row.reference} onChange={(event) => update(row.key, { reference: event.target.value })} />
              </>
            )}
          </li>
        ))}
      </ul>
      <dl className="flex flex-col gap-1">
        <div className="flex justify-between">
          <dt>Paid</dt>
          <dd>{money(summary.paid)}</dd>
        </div>
        <div className="flex justify-between">
          <dt>Remaining</dt>
          <dd>{money(summary.remaining)}</dd>
        </div>
        {summary.change > 0 && <div className="lead-style">Change {money(summary.change)}</div>}
      </dl>
      {message && <span role="alert" className="caption-style text-danger">{message}</span>}
      {offline && <span role="status" className="caption-style text-warning">You&apos;re offline. Reconnect to complete the sale.</span>}
      <Button variant="primary" size="md" className="min-h-11" disabled={!summary.complete || parseError !== null || offline || pending} onClick={complete}>
        {pending ? "Completing…" : "Complete sale"}
      </Button>
    </div>
  );
}

export default function PayDialog({ open, onOpenChange, ...props }: PayDialogProps) {
  const [prevOpen, setPrevOpen] = useState(open);
  const [openCount, setOpenCount] = useState(0);
  if (open !== prevOpen) {
    setPrevOpen(open);
    if (open) setOpenCount((count) => count + 1);
  }
  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent>
        <PayForm key={openCount} {...props} />
      </DialogContent>
    </Dialog>
  );
}
```

```tsx
  const [approval, setApproval] = useState<{ id: string; maxBps: number } | null>(null);
  const [query, setQuery] = useState("");
  const [category, setCategory] = useState("");
  const [notice, setNotice] = useState<string | null>(null);
  const [variantProduct, setVariantProduct] = useState<RegisterProduct | null>(null);

  const [payOpen, setPayOpen] = useState(false);
  const [approvalOpen, setApprovalOpen] = useState(false);
  const [customerOpen, setCustomerOpen] = useState(false);
  const [done, setDone] = useState<Done | null>(null);
  const [lastOrderId, setLastOrderId] = useState(props.lastOrderId);

  const categoryIndex = useMemo(() => new Map(props.categories.map((entry, index) => [entry.id, index])), [props.categories]);
  const visible = useMemo(() => searchProducts(props.products, query, category), [props.products, query, category]);
  const pricing = useMemo(() => {
    try {
      return { priced: priceCart(cartInputs(lines), discountInput(orderDiscount), props.pricesIncludeTax), error: null };
    } catch (error) {
      return { priced: null, error: error instanceof CartError ? error.message : "Something in this sale isn't valid." };
    }
  }, [lines, orderDiscount, props.pricesIncludeTax]);

  const shareBps = pricing.priced ? discountShareBps(pricing.priced.subtotal, pricing.priced.discountTotal) : 0;
  const overLimit = props.role === "cashier" && shareBps > props.maxCashierDiscountBps;
  const approved = overLimit && approval !== null && approval.maxBps >= shareBps;
  const needsApproval = overLimit && !approved;
  const canPay = lines.length > 0 && pricing.priced !== null && !needsApproval && online;

  function add(product: RegisterProduct, variant: RegisterVariant) {
    setLines((current) => addToCart(current, product, variant));
    setNotice(null);
  }

  function pick(product: RegisterProduct) {
    if (product.variants.length === 1) add(product, product.variants[0]);
    else setVariantProduct(product);
  }

  function onSearchKey(event: KeyboardEvent<HTMLInputElement>) {
    if (event.key !== "Enter") return;
    event.preventDefault();
    const match = findByCode(props.products, query);
    if (match) {
      add(match.product, match.variant);
      setQuery("");
    } else if (visible.length === 1 && visible[0].variants.length === 1) {
      add(visible[0], visible[0].variants[0]);
      setQuery("");
    } else if (visible.length === 0) {
      setNotice(`Nothing matches "${query}".`);
    }
  }

  function reset() {
    setLines([]);
    setOrderDiscount(null);
    setCustomer(null);
    setApproval(null);
    setQuery("");

      approvalId: approved && approval ? approval.id : null,
      customerId: customer?.id ?? null,
      payments,
    });
    if (!result.ok) return result.error;
    setPayOpen(false);
    setDone({ orderId: result.orderId, receiptNumber: result.receiptNumber, change: result.change });
    setLastOrderId(result.orderId);
    reset();
    return null;
  }

  return (
    <section id="register" className="flex min-h-0 min-w-0 flex-1 flex-col">
      <PageHeader
        title={`Register · ${props.registerName}`}

              onOrderDiscount={() => setDiscountTarget({ kind: "order" })}

            : orderDiscount
        }

        onApply={(discount) => {
          if (discountTarget?.kind === "line") setLines((current) => setLineDiscount(current, discountTarget.line.variantId, discount));
          else setOrderDiscount(discount);
          setDiscountTarget(null);

      />
      <PayDialog open={payOpen} onOpenChange={setPayOpen} total={pricing.priced?.total ?? 0} currency={props.currency} offline={!online} money={money} onComplete={complete} />

        onOpenChange={setCustomerOpen}
```

```markdown
## Register

- **Tills:** each device picks its register and opens the till with the starting cash. Closing the till compares counted cash with what the sales say should be there.
- **Selling:** tap products, search, or scan a barcode (any USB scanner that types works). Discount a line or the whole sale by % or amount. Cashiers can discount up to the store's limit (20% by default, set in Settings → Stores); bigger discounts need a manager or owner to approve on the till.
- **Payments:** cash with change, card, other, or any split of them. Card payments are recorded, not charged — use your existing card terminal.
- **Receipts:** printed from the browser at 80mm width, so any receipt printer your device can print to works. Reprint the last receipt from the register.
- **Totals are always calculated by the database** from current prices, so they can't be changed from the browser.
```
