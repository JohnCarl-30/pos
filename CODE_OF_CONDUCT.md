# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- **Be kind and patient.** People here range from shop owners trying it out to experienced developers.
- **Critique ideas, not people.** Disagree openly and politely about code and design.
- **No harassment of any kind:** no insults, personal attacks, sexual content, or publishing someone's private information.
- **Help newcomers.** A first issue or pull request deserves a welcoming reply.

## Reporting

If someone breaks these rules, contact the maintainer, [@JohnCarl-30](https://github.com/JohnCarl-30), through GitHub. Reports are kept confidential. The maintainer may remove comments, close issues, or block people who don't follow this code, in line with the Contributor Covenant's enforcement guidelines.
